# Parallax Demo
This is a small demo to demonstrate how to effortlessly implement parallax scrolling effects with Kasane2D.
- Press Left/Right to move the camera.
- Hold left shift to double the movement speed.
- Press 1, 2, or 3 to toggle the 3 layers on and off.
- Press Escape to exit.
