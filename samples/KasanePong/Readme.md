# KasanePong
This sample is an implementation of the classic game pong with Kasane2D. It demonstrates sprite and background rendering, collision detection, input handling, and game state management.

The left paddle is controlled with W/S and the right paddle is controlled with Up/Down. Space starts the game and Escape exits the game.
